# Ali Raza Niazi — Developer Portfolio

A responsive, animated personal portfolio built with plain HTML, CSS, and JavaScript.

## Preview

After enabling GitHub Pages, the site will be available at:

https://alirazaniazi804.github.io/portfolio-websites/

## Features

- Responsive layout for desktop, tablet, and mobile
- Animated particle background and 3D-inspired orbit hero
- Scroll-reveal sections and animated typing introduction
- Skills, featured projects, current learning focus, and contact links
- Reduced-motion accessibility support
- No build step, package installation, or API key required

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to finish deploying. The public URL will appear in the Pages settings.

## Customize

Edit `index.html` to update the introduction, project links, skills, and social links. Keep all experience and skill claims accurate and current.
